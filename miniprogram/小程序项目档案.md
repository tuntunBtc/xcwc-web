## 四、已用组件与接口

**自定义组件**：暂无（均为原生页面 + 全局 `app.wxss`）。

**已用 wx API / 生命周期**：
- `App.onLaunch` / `App.onShow`（`options.query` 入口参数）
- `Page.onLoad`（`options.birdCode` / `options.scene` / `options.q`）
- `wx.getWindowInfo` / `wx.getSystemInfoSync`、`wx.getMenuButtonBoundingClientRect`（领养页安全区）
- `wx.setStorageSync` / `getStorageSync` / `removeStorageSync`（`utils/store.js`）
- `wx.navigateTo` / `wx.reLaunch` / `wx.navigateBack`、`wx.showToast`、`getCurrentPages()`

**入口参数约定（本轮确立）**：
- 页面路径：`pages/adopt/adopt`，参数名统一 `birdCode`，值不改写、只搬运与解码
- 统一解析模块 `utils/entry.js`：`readBirdCode(options)`（页面级）、`readBirdCodeFromLaunch(options)`（App 级）、`buildAdoptUrl(code)`
- 关键边界：App 的 `options.scene` 是数值场景值（1001 / 1047 / 1286…），**不可**当编码解析；小程序码自定义 scene 才是编码，上限 32 可见字符，只放纯编码
- 调试期自定义编译条件写在 `project.config.json` 的 `condition.miniprogram.list`（3 条：query / scene / 缺码）

**待接服务端接口**：
- `GET /api/birds/by-code/{birdCode}`：真实实体资料（等备案域名 + request 合法域名）
- 服务端换取跳转凭证：`generate_urllink` / `generatescheme` / `wxacode.getUnlimited`（`access_token`、AppSecret 只在服务端，禁止落前端或文档）
- `code2session` + 手机号组件：后续登录（计费与额度需以官方最新规则核实）
- `wx.getWeRunData`：步数兑换叽分，需 `scope.werun` 授权 + 服务端 session_key 解密 + 按北京时间幂等结算

## 五、待办与已知问题

1. **正式凭证还不能生成**：URL Link / Scheme 仅对已发布小程序开放（未发布报 `85079`）；还需非个人主体、HTTPS + ICP 备案。
2. **已发行 NFC 实体标签策略未拍板**：建议保留 `https://www.jiuyouji.art/register.html?birdCode=…` 原地址做中转页（微信内跳小程序、微信外走动态 URL Link），避免标签重制与短链 30 天失效；官方也提供云开发静态网站免鉴权跳转方案，需以官方最新规则核实。
3. **口径冲突**：`docs/V1.1030-REQUIREMENTS.md`、根 `AGENTS.md`、本仓 `AGENTS.md` 仍写「不做微信小程序、不接微信步数、账号密码登录」，需授权后同步。
4. **UI 复刻**：上一轮审核结论为「原生逐页 1:1 复刻」，P0（token / 安全区 / 自定义 tabBar / 素材分包）+ P1（领养→小窝→城市→商城→我的）尚未开工；web-view 方案已否决（自定义导航对其无效）。
5. **验证边界**：本机未安装微信开发者工具，未做原生编译、模拟器与真机验证；WXSS 百分比叠层、input 层级、WebP 基础库要求待复核。应用预览卡无法模拟启动参数，带参调试必须在开发者工具里用编译条件。
6. **功能边界**：步数为 mock、商城为只读快照、领养为本机写入；无登录、无订单、无淘宝外链。
