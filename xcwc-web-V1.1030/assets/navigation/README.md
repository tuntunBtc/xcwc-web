# 纸卷导航底图 V1

`navigation-scroll-v1.png` 为所有页面共用底部导航的无文字装饰图，包含纸卷、木边、小鸟、藤叶；图标、文字、选中态和点击区域由 HTML/CSS 渲染。图片外部为透明背景，不包含任何导航标签或固定业务值。

生成方式：内置 image_gen（imagegen skill），以用户 2026-11-02 提供的导航截图为编辑参考。保留原始生成文件，项目使用本目录副本。不要以该素材新增“认领”等导航项。

Wide horizontal asset, straight on front view, nearly flat perspective. Keep whole ornament within image, no clipping or cropped spindles. Scroll very wide approximately 5:1 visible width/height, include upper bird perch and leaves. Minimal transparent padding outside ornament. Do NOT create a mockup, no text, no symbols, no screen, no hands. This is the actual production navigation background to sit behind four real HTML navigation buttons.
